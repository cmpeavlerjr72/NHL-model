## Build

- Rr: a team's counts from its home (non-neutral) games are not accumulated; neutral-site games count as road for both teams. Ra: each game's blocked counts (for and against) divided by exp(arena_f) of the game's as-of arena factor (past games only) before accumulating. b 1000, w 0.7. `created_at < puck_drop` asserted in code (`assert_pregame`, in the rating builder and again on the output).
- Correlation of the as-of ratings with the arena factor (fold-2 train): incumbent 0.19 / 0.14 (own / opp); Rr -0.06 / -0.01; Ra 0.01 / 0.02. The arena content is removed.
