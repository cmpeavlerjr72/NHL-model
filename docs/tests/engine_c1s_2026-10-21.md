## 1. Engine (`src/nhl_sim/engine/sim.py`; one engine, default-off flags inside `tables["attr"]`)

All four components are served from lookup tables. Nothing calls a model inside the sim loop.

- **INV-57: per-game stage-4 level.** On when `attr["game_mult"]` (G, 3, 78) is present, used in place of `era_mult`.
  - Each entry is s_M1K500[game, level group, cell] / s_train[level group, cell], from `mix_level_v2.parquet` (the SL-R6 D35 level).
  - It is applied to the L0s `state_pdf` row in the same way as `era_mult`: multiply, cumsum, renormalise.
  - Carrying both `era_mult` and `game_mult` is refused.
- **INV-54: B0 with its own 4v4 / 3v3 groups.** On when `p_block_game` has shape (G, 5, 2), indexed by the team-view state. A (G, 3, 2) table is served exactly as before.
- **Miss S0t STAND-IN.** On with `attr["p_miss_game"]` (G, 3, 2, 78) = [game, rating group, period type, class].
  - After the class draw, each unblocked attempt is drawn as a miss or a shot on goal, on a new RNG stream `attempt_miss`.
  - The label `stand_in["miss"]` is required.
- **Goal C1s.** On with `attr["goal"]`; the miss and goal flags each require the other. A shot on goal scores with probability sigmoid(cls_logit[class, st] + game_logit[g, team, st] + sc_logit[sc7]), on the stream `attempt_goal`. This replaces the xG_ref stub draw.
  - `game_logit` bakes in, at table-build time:
    - the level M1 K500 delta;
    - the C1s coefficients (strength group, home, b2b own / opp, arena);
    - team finishing at its fixed scale;
    - s_t(game date, H90 P2000) x z(starter), where z is the standardised as-of goalie rating.
  - The starter is the box-score starter (`load_goalie_box`, `starter`); all 2,796 team-games have exactly one.
  - Two labels are required: a model label, and an `oracle_goalie` label containing "oracle".
- **Outputs (when the goal flag is on):**
  - `attr_sog` and `attr_gprob`: shots on goal and summed C1s probability by (team, team-view state);
  - `goal_model` = `goal: C1s (provisional, D40)`;
  - `oracle_goalie`;
  - `goalie_against` (G, 2), which gives the per-goalie aggregation.

  `stand_in` now also names `miss`. xG_ref is still summed per unblocked attempt (`attr_xg`) for G3.
- **Builders and parity helpers:** `src/nhl_sim/engine/c1s_tables.py`. The served-value functions `block_prob`, `class_cdf`, `miss_prob` and `goal_prob` are the ones the draw itself calls.

### INV-54 construction (labelled choice)

- **5v5 / PP / PK:** unchanged. These use the SB-R1 B0 coefficients and their M1 K500 level, and the ES level group still pools 5v5 + 4v4 + 3v3 + EN, as in the B0 fit.
- **4v4 and 3v3:** each gets its own M1 K500 as-of league block share, built as follows:
  - The level is computed by the same function as the ES / PP / PK groups (`block.data.asof_levels`, run on that state's rows). A recompute of ES / PP / PK through the same call reproduces `level_v1.parquet` exactly (max deviation 0).
  - It enters as a logit offset with coefficient 1.
  - One intercept is fitted under the offset by the B0 fitting code (`fit_logit_offset`) on the fold-2 training rows.
- **One intercept per new group, pooled over period type.** Reason: 3v3 has 3 regulation training rows with 0 blocks, so no MLE exists for a regulation cell. Each new group therefore has one form.

| group | coefficient | training share | n train (reg / OT) |
|:--|--:|--:|:--|
| 4v4 | -1.2840 | 0.2194 | 5,552 (5,302 / 250) |
| 3v3 | -1.7030 | 0.1523 | 4,426 (3 / 4,423) |

A per-period-type form is not used here; adding it would be a new construction for the PM to rule on.

## 4. Tests (`tests/engine/test_sim_c1s.py`, 26 tests; full suite 218 passed, 1 xfailed)

- **Flag off: bit-identical to 7fac157.** Every output array matches by sha256 on 13 cases. The fixture is `tests/fixtures/sim_c1s_flag_parity.json`, recorded before the edit by `scripts/diag_engine_c1s_parity_fixture.py`. The cases are:
  - the 10 D32 stand-in fixture cases;
  - 3 cases with the D32 stand-ins switched on, as served before this change (synthetic, synthetic T2, real games).

  The older attr / era / T2 / stand-in parity tests still pass.
- **Wiring.** Each of these reproduces the reference run bit for bit:
  - `game_mult` = `era_mult`[era of the season] reproduces the era-levelled run;
  - a (G, 5, 2) block table whose 4v4 / 3v3 rows equal ES reproduces the (G, 3, 2) run;
  - p_miss = 0 with goal logit = logit xG_ref reproduces the xG_ref draws (on every pre-existing output key).

  Counts are conserved: SOG <= unblocked, goals <= SOG, and attempt-path goals equal the score.
- **Served vs offline.** One test for each of the four components, each < 1e-6. The B0 test also checks that the 4v4 / 3v3 rows are served their own groups.
- **Seal.** `c1s_tables.starters(..., season=20252026)` raises `SealedSeasonError`.
- **Markers.** The output carries `oracle_goalie`, `goal_model` and a `stand_in` that names `miss`. Four cases are refused: an unlabelled miss stand-in, a goal without an oracle label, miss without goal, and goal without miss.
